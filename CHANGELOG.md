## [1.0.0](https://github.com/bonfiglioalessio/bonfiglioalessio.github.io/releases/tag/v1.0.0) (2026-08-25)

### 🚀 Features

* **cockpit:** interactive satellite HUD with real-time CLI terminal emulator
* **canvas:** full-screen GPU-accelerated interactive starfield with constellation connections
* **stack:** orbital category constellation graph with categorized skill cards
* **projects:** cyberpunk telemetry project showcase with live interactive preview lightbox
* **experience:** vertical orbital timeline with mission milestones and achievement diffs
* **audio:** procedural Web Audio API SFX synthesizer and ambient deep space soundscape
* **theme:** cyberpunk cyber-orbital theme with Tailwind CSS, SCSS, glassmorphism, and neon glow pulses
* **data:** centralized, fully typed data layer (`portfolio.json`) with runtime fallback
* **devops:** automated GitHub Pages deployment workflow with zero-config CI/CD
